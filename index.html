WXP Agents · Edit with Copilot Basic

One consistent gesture across Excel, Word and PowerPoint — open the file, click Edit with Copilot, describe the change. Three files, three prompts.

📊 Excel · clean & analyse the DSR

In Contoso_Active_DSR_March_2026.xlsx, clean up Daily Sales CA09 into a new sheet DSR_Clean (promote row 8 to headers, drop empty columns, IDR-format numbers). Then add YoY Var % vs 2025, MTD Var vs Target %, and traffic-light formatting (red <70%, amber 70–95%, green ≥100%). Finish with a one-paragraph MTD snapshot.

📝 Word · expand the Store Action Plan

In Store_Action_Plan_Draft.docx, expand the seed notes into a full action-plan memo. Tone: firm but supportive. Sections: Context, Findings, Required Actions (SMART, with owner + due date by 30 April), Support from HQ. Keep it under 1.5 pages.

🎞️ PowerPoint · build the COO deck

In Q1_COO_Briefing_Template.pptx, build a 5-slide COO briefing from the Word memo: title · Q1 highlights · underperformers & anomaly days · actions with owner/due-date · the ask. Add a chart slide (Sales 2026 vs 2025 vs Target) and write 3-bullet speaker notes per slide.

Researcher Premium

Deep multi-source web research with citations. The agent we send to Jakarta before we commit to a play.

🔬 Competitor benchmark · Jakarta flagships

Researcher: build a benchmark on how Nike, Adidas and Decathlon flagship stores in Jakarta are driving Q1 2026 footfall — events, run-clubs, exclusive drops, channel rules. Output a structured brief with sources I can cite in my COO deck.

🏃 Run-club playbook

Researcher: study how Nike Run Club, ASICS Front Runner and Lululemon Sweat Collective build retention in Southeast Asia. What's the format, cadence, incentive structure, and reported uplift in footfall? Give me a one-page playbook I can adapt for CA PIM 1.

📰 Indonesia Q2 retail signals

Researcher: what are the consensus economic, consumer-spending and weather signals for Indonesia in Q2 2026 that would materially affect sports/lifestyle retail at a Jakarta mall? Cite official sources where possible. Output the top 5 with implication for CA PIM 1.

Analyst · DSR Premium

Python on the workbook — forecast, anomaly scan, board summary. The reasoning agent doing the analyst's heavy lifting.

🔮 Month-end forecast vs 5.4B target

Analyst: using the daily 2025 sales pattern and actual March 2026 days-to-date in DSR_Clean, forecast the remaining days and the month-end total. Show forecast vs the 5.4B IDR target, the probability of hitting it, and a chart with actuals, forecast band and target line.

🚨 Anomaly scan with hypotheses

Analyst: flag anomalous days in March 2026 vs the 2025 pattern using a z-score on daily variance %. Return a table — Date · Day · Daily Sales 2026 · Expected · Z-score · likely-cause hypothesis (cross-reference the Reason column on the Daily Target sheet). Plot a chart highlighting the outliers.

📝 Board-ready summary

Analyst: produce a COO board summary on CA PIM 1 March 2026. Include headline KPIs (MTD Sales, YoY%, vs Target%), top 3 takeaways, top 3 risks, top 3 recommended actions, and a one-paragraph narrative. Output in markdown ready to paste into the Word memo.

Cowork · The finale

Cowork — build a live HTML Operations Dashboard Premium

Paste this single prompt into Cowork (with the DSR attached). Cowork generates a self-contained HTML file you can open immediately in the browser and demo to the COO. It includes interactive slicers so you can slice and dice the data live in front of the audience — every KPI, chart and table re-renders on the fly.

🚀 The finale prompt

Using the data in Contoso_Active_DSR_March_2026.xlsx (store CA PIM 1, March 2026, Target 5.4B IDR), build me a single self-contained HTML file called Contoso_Active_PIM1_March_2026_Dashboard.html for the COO review.

Layout:
• Clean executive layout with a Contoso Active header (orange #E25522 / charcoal #1F2937).
• A sticky slicer bar just below the header, then KPI tiles, then charts, then tables, then Key Insights.

Interactive slicers (Power BI–style — drive every visual on the page):
1. Date range — twin date pickers (default: full March 2026) with quick buttons for W1, W2, W3, W4, W5, W6, MTD, "Weekdays only", "Weekends only".
2. Day of week — multi-select pills Mon–Sun (default all on).
3. Channel — toggle buttons for Store, Digimap, Both (default Both).
4. Compare to — radio: 2025, Daily Target, Both (default Both).
5. Anomaly filter — checkboxes: Show all days / Only anomaly days (|z-score| ≥ 1.5 vs 31-day mean) / Exclude anomaly days.
6. Reset button that restores defaults.
Every slicer change must instantly recompute KPIs, all charts, the best/worst-day table, and the Key Insights text (no page reload). Show an active-filter summary chip row above the KPIs (e.g. "W2–W4 · Weekdays · Store only · 14 days").

KPIs (4 tiles, react to slicers):
• MTD Sales 2026 (filtered) · YoY vs 2025 % · vs Target % · Forecast Month-End vs 5.4B Target. Each tile has a 14-pt sparkline of the filtered daily series.

Charts:
• Daily line chart: Daily Sales 2026 vs Daily Sales 2025 vs Daily Target. Anomaly days marked with a dot & tooltip reason. Drag-to-zoom.
• Weekly bar chart W1–W6 (2026 vs 2025), highlights the selected weeks.
• Store vs Digimap channel split donut with % labels.
• Click-through: clicking a bar/point sets that period as the active filter.

Tables:
• Top-5 best and bottom-5 worst days within the current filter, with variance % vs target coloured red/green, and a reason column (auto-filled for known anomalies: 9 Mar POS outage, 14 Mar run-club + HOKA drop, 27 Mar Digimap cannibalisation).

Key Insights (auto-narrative):
• Re-writes itself every time a slicer changes — YoY momentum, biggest swing day in the selected range, target attainment probability, and one channel observation.

Tech: Single self-contained .html file. Inline CSS. One chart library via CDN (Chart.js or ECharts is fine). All data embedded in a JS array. No build step. Must open and work offline once downloaded.

Agent Builder

Build the Store Ops Coach agent Premium

The dashboard tells you what happened. The agent makes sure every store manager knows what to do about it — 24/7, in their language, grounded on Contoso Active's own playbook.

🛠️ Build the Store Ops Coach

Open Agent Builder. Create an agent called Store Ops Coach. Description: "Helps Contoso Active store managers understand their daily/MTD performance, the action plan they owe HQ, and what good looks like." Ground it on these files in OneDrive/SharePoint:
• Contoso_Active_DSR_March_2026.xlsx · daily & MTD numbers, anomaly reasons
• Store_Action_Plan_Draft.docx · required actions, owners, due dates
• Market_Research_Notes.docx · Q1 context & what competitors are doing
• Sample_Emails_Teams.docx · recent regional chatter
Tone: firm but supportive. Always answer with the number first, then the action. Always cite the source file. Refuse to answer questions outside store operations.

🧪 Test prompts for the agent

Once published, try these as a store manager would:
1. "How did CA PIM 1 do in March vs target? Why?"
2. "What action am I owed on the 27 March Digimap day?"
3. "Show me my three worst days and what HQ wants me to do about each."
4. "What are other Jakarta sports flagships doing differently this quarter?"
5. "Translate the action plan into Bahasa Indonesia for my floor staff."

📣 Publish & share

Publish the agent to the Contoso Active Operations channel in Teams. Set it so any store manager can chat with it from Teams or M365 Copilot. Add a default starter prompt: "What does HQ need from me this week?"
